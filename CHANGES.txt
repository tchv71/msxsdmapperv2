01/01/2020:
Removed I/O port created for updates. Modified update method to standard ASCII16.
Frame 1 for Flash reading; Frame 2 for reading and writing (only if bank > 7).
Added disk change detection.
Improved SPI port asynchronous mode.
The register for selecting page banks is now fully decoded (6000h and 7000h).
The SPI window is now always active.
Changed registers:
- For SPI data access, the window is 7B00h to 7EFFh. 
- For control and status, it is 7F00h.
Changed current card selection method: bits 1 and 0 of register 7F00h select the card:
- "00" selects no card; 
- "01" selects the 1st card; 
- "10" selects the 2nd card.
To read status: depends on the selected card. If no card is selected, it reads the status of the external switches; if a card is selected, it reads the status of the disk change, card insertion, and write protection.
